# 30 Days for 30 Deep Learning Models
*A Deep Learning Framework for Beginners and Easy Model Experiment*

When reproducing a deep learning foundational architecture papers recently, I found that writing data processing and training code from scratch is extremely time-consuming. When I was a deep learning beginner before, I also spent considerable time on these repetitive tasks. While frameworks like PyTorch Lightning and ESPnet exist to assist with such work, they aren't specifically designed for beginners or paper reproduction. Therefore, I created this repository to help beginners focus better on learning deep learning architectures while eliminating repetitive work.

Additionally, I aim to reimplement classic deep learning models on this framework as part of my own learning journey, while also helping other deep learning beginners. That's why I named this repository "30 Days for 30 Deep Learning Models". You can join me over the next 30 days to reproduce 30 classic deep learning models, gaining deeper insights into deep learning. Each model comes with its own tutorial below. If you find this repository useful, please give it a star! Contributions of additional datasets and models are also welcome to help everyone learn deep learning more easily! Thanks very much!
